# 测试指南

## 自动检查

运行 `python scripts/run_tests.py`。统一入口检查测试脚本登记状态，然后执行自动回归。CI 在 Ubuntu/Windows 与 Python 3.10/3.12 组合运行这条入口，并在 Windows 上单独构建测试安装包、执行安装冒烟检查。开发环境细节见 [构建指南](BUILDING.md)。

## 手工检查

桌面界面、托盘、安装/卸载和真实平台投递需要手工验证。使用获授权的测试账号、频道和群；不要在生产群里发送测试消息。记录版本/提交、复现步骤和预期结果。

## 数据保护

不得将 .env.prod、data/、数据库、完整日志、真实平台标识符或消息内容提交到测试报告。确需提交日志时，先删去凭据、OpenID、频道/群组 ID 和消息正文。
