# 隐私与本地数据说明

WRelay 是由使用者自行配置的本地转发程序，不要求创建 WRelay 云端账号。机器人与面板将配置、运行状态和诊断数据保存在本机项目目录的 data/ 中；账号凭据由本机 .env.prod 保存。请勿把这些文件或未经处理的日志提交到 Issue、Pull Request 或公开仓库。

## 本机会保存什么

根据启用的功能，运行数据可能包含：

- Discord 频道、RSS 来源和 QQ 接收群的配置与标识符；
- QQ 用户/群 OpenID、注册审核状态及转发组配置；
- 去重游标、失败重试队列、统计、运行日志和诊断状态；
- 最近 200 条投递追踪记录。记录包含消息与频道标识、目标群标识、投递状态以及最多 120 个字符的消息摘要；
- .env.prod 中的 QQ、Discord 和翻译服务凭据。

运行日志可能包含服务错误和用于诊断的上下文。分享前请检查并遮盖身份、群组、频道、消息内容和凭据。

## 网络请求与第三方服务

- Discord → QQ 功能会从 Discord API 读取已授权频道消息，并按用户配置发送到 QQ Bot。
- X/Bilibili 自动投递通过用户配置的 RSSHub 地址读取来源，再将符合规则的内容发送到 QQ。
- 开启自动翻译后，待翻译文本会发送给所选翻译服务：腾讯 TMT 或用户配置的 OpenAI 兼容 API。对应服务会按自己的条款和隐私政策处理该文本。
- 用户手动检查更新时，程序会查询 GitHub 的 WRelay 发布信息；不会因此自动下载或安装更新。

网络请求由用户启用的功能和配置决定。请不要转发你无权处理的私人消息；开启翻译前，请确认相关内容可以交给所选服务处理。

## 保留与删除

数据保存在本机，直到使用者清理或覆盖。卸载程序会保留配置和运行数据。需要清除时，先退出桌面端和机器人，再删除项目的 data/ 与 .env.prod；这会同时删除配置、游标、日志、待重试数据和本机诊断报告。请自行检查并另外处理备份目录及你手动导出的副本。
