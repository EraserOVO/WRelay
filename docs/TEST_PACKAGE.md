# WRelay 测试包使用说明

测试包用于检查 Windows 安装流程和候选构建。它不代表正式发行，也不表示已完成代码签名、安全审计或真实投递验收。

1. 使用 Windows 10/11 x64，并核对发布者提供的 SHA-256 校验值。
2. 测试安装包可能未签名，Windows 可能显示未知发布者；确认来源可信后再决定是否运行。
3. 先退出其他 WRelay 版本。测试版与其他版本使用相同机器人服务端口，不能同时运行。
4. 首次配置使用专门的测试 Bot、来源频道和接收群。真实消息投递只应发生在你有权操作的环境中。
5. 测试完成后，反馈构建编号、复现步骤和必要的脱敏日志片段；不要发送 .env.prod、Cookie、Token、AppSecret、OpenID 或私人消息。

卸载会保留测试版配置与运行数据。需要清除时，退出程序后手动删除测试安装目录中的本机数据。
